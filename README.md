### About me

I'm a Product Engineer at iklo, a childcare platform. I joined as an intern when it was just getting started, and I'm still here. The app is used by 6,000+ children across partner centers.

Most of it was built from scratch across phones, browsers and servers. I started as the only person on mobile (Flutter) and picked up web and backend as the product needed them. I like the messy early stage, where the requirements are half-formed and someone just has to start. I also guest lecture on UI/UX and product thinking for design students.

### Shipped at iklo

- Moved the parent app from native to a Next.js PWA
- Built the Ask iklonaut chatbot in 2 days, from UI and backend to admin tools
- Cut page lag ~30%, crashes ~40% and upload size ~60% on low-end phones
- Built a real-time kiosk display in one day after spotting a child-safety gap at partner centers
- Found and fixed a data-exposure risk in our public API docs
- Rolled out features behind flags so launches were safer

### Built on my own

- **HanapHire**: a gig-hiring marketplace where an AI agent scores every applicant (Next.js, TypeScript, Supabase)
- **MediLearn AI**: a study platform for medical students with Gemini-generated quizzes and adaptive study plans
